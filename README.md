# X Squadron: The Last Homeland

University of Adelaide introductory programming, 2018–2019 study period (exact submission year not independently established). Processing team project by Chen Jiang, Wangshu Xu, Chenhui Yang and Yuhang Xie. Chen contributed animation, algorithms, laser/explosion effects, movement, enemy tracking, bridge version, testing, reports and presentation.

Selected original code, with synthetic media replacements; full source and commercial-looking audio retained privately. Public historical selection is sanitized, not byte-identical to the full original.
